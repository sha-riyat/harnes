Eight stops.
One of them is you.

Every run takes the same road. Pick a stop to see who works there, with what, and what it leaves behind.

◄················ CHANGES or not ready: back to the workers, as a new round

Orchestrator Sonnet 5.5 · high

Turns your message into one complete brief and starts the run. Quick questions it answers itself.

Tools
crew_start · crew_status · scout · os_route
Leaves
.harnes/runs/<id>/

Planner Opus 5.5 · medium

Splits the task into lots and waves. Lots in the same wave never share a file, so workers never collide.

Tools
os_brief · Read · Grep · ctx_search
Leaves
plan.json, one thread per lot

Teacher Sonnet 5.5 · high

Fixes the bar before anyone works: the criteria, the evidence each one needs, and when to involve you.

Tools
os_brief · validation pack
Leaves
bar.json

Workers × N Sonnet 5.5 · high

Each reads its lot thread, touches only its own files, then writes and runs its own end-to-end test.

Tools
thread_read · thread_post · ctx_execute · e2e_observe · e2e_check · e2e_save
Leaves
reports/<lot>-r<n>.json

e2e suite no model

Runs every spec in a real browser. Steps already resolved replay from the cache without a model call.

Tools
harnes-e2e run · Chrome or Edge over CDP
Leaves
results per spec, .harnes/e2e/cache/

Reviewer Sonnet 5.5 · high

Reads the diff against the plan and the real test results. PASS moves on; CHANGES go back to the lots.

Tools
diff · thread_post · quality and security packs
Leaves
review-<n>.json

Teacher Sonnet 5.5 · high

Holds the results against its own bar. Ready goes to you; not ready goes back to the workers.

Tools
bar.json · the results
Leaves
gate-<n>.json, threads closed

You the last stop

Read the summary and the proposed commits, one per lot. Test it yourself, then approve.

Tools
the chat
Leaves
commits, only once you say so

Any role can send a scout (Sonnet 5.5 · high) for a short errand: find code, sum up a file, run one command.
