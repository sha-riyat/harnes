Un chat.
Tout un équipage.

harnes est un cockpit de bureau pour agents de code. Vous parlez à un orchestrateur ; il planifie, recrute, teste, et ne revient que lorsque la barre est atteinte.

Le trouver sur GitHub Voir l'interface

Ce que vous voyez

Une feuille, une question à la fois. Ce qui vous attend vient à vous sous forme de carte.

Des cartes qui répondent

Répondre replie la carte en une ligne, et l'agent reprend son travail.

Questions

Un agent pose une question typée : un choix, un oui ou non, ou quelques mots. Une valeur par défaut tient si personne ne répond.

Permissions

Chaque commande attend Allow once, Always ou Deny. Rien ne tourne dans votre dos.

Confiance

Avant qu'un équipage démarre, harnes lit la config du projet lui-même et bloque le lancement sur tout point sérieux tant que vous ne l'avez pas lu.

Six rôles.
L'un d'eux, c'est vous.

Chaque run prend la même route : brief, plan, barre, travail, test, revue, gate, vous.

  • Orchestrateur Sonnet 5.5 · high

    Votre seul interlocuteur. Transforme vos messages en runs et rend compte.

  • Planner Opus 5.5 · medium

    Découpe la tâche en lots et en vagues, pour que les workers ne partagent jamais un fichier.

  • Teacher Sonnet 5.5 · high

    Fixe la barre avant que personne ne travaille, puis y confronte les résultats.

  • Workers Sonnet 5.5 · high

    Chacun construit un lot dans son propre worktree et le teste.

  • Reviewers Sonnet 5.5 · high

    Lisent le diff face au plan et aux vrais résultats de test.

  • Scouts Haiku 5.5 · high

    Petites missions : trouver du code, résumer un fichier, lancer une commande.

Vous êtes la dernière étape : lisez le résumé et les commits proposés, testez, puis approuvez. Rien n'est commité sans vous.

Trois étapes

Windows 11 avec Rust, Zig, Node via nvm et Claude Code connecté. Rien d'autre à installer.

  1. Le compiler

    git clone https://github.com/sha-riyat/harnes
cd harnes/app; npm install
npm run app

  2. Ajouter un projet

    + projects
C:\work\calculator

  3. Dire quoi construire

    Ajoute une page contact
qui envoie un e-mail.

Lancez votre premier équipage.
